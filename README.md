# 出行

「出行」从用户授权的数据源导入并在设备端管理行程信息。当前已实现从 Gmail 主动导入 12306 购票邮件、行程确认、本地持久化、设备端乘车提醒，以及可选的 Google Wallet 导出。

## 当前范围

- `core`：与 Android 无关的统一行程模型和邮件解析器
- `app`：Android/Compose 行程管理界面、Gmail 与截图导入和 Room 本地存储
- Gmail Token、邮件正文、截图和 OCR 结果只在设备端使用，不发送到自建服务端
- 导入默认忽略已经出发的行程，可在设置中关闭过滤以保留历史行程
- 不处理检票二维码
- Android 应用是行程管理和提醒的主要入口
- Google Wallet 是可选导出目标，使用 Android SDK 的未签名 Pass 流程，不建设自有签名服务
- 首页使用紧凑行程卡片，完整信息和操作集中在行程详情弹窗
- 支持从首页向左滑动归档行程，也可从归档页恢复；归档时会关闭该行程的提醒
- 行程详情支持二次确认后删除，删除后可重新导入同一行程
- 可选择在未来行程出发时自动归档，默认关闭；不追溯此前已结束的行程，自动归档后手动恢复也不会再次归档
- 添加入口统一为首页右下角按钮；截图通过系统照片选择器导入，并使用设备端中文 OCR 读取文字
- 设置页管理过期行程过滤、自动归档、新行程默认提醒、提醒时间、Google Wallet 入口和浅色/深色主题
- 应用提醒默认关闭，可设置新行程默认值并为单个行程开关；已结束的行程不能开启提醒
- 经用户授权精确提醒后，在设定时间显示普通锁屏通知；Android 16 在设定时间升级为 Live Update，发车后自动结束
- 通知支持“已上车”和“取消提醒”：前者结束提醒并归档，后者只结束提醒，不影响独立的自动归档任务
- 发车前提醒支持 30 分钟～12 小时，实时状态支持 15 分钟～1 小时，均以 15 分钟为调整粒度

## 本地环境

- JDK 17
- Android SDK 36

```bash
./gradlew :core:test
./gradlew :app:assembleDebug
```

正式 `applicationId` 为 `com.neko7ina.wallet.assistant`。
