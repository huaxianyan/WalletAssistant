# 出行 v1.1.0

这是一次功能更新，新增出行概况首页和三项底栏，行程页的切换方式与归档操作也有调整。已保存的行程数据、邮箱配置、提醒设置和 Google Wallet 卡片不受影响，可以直接覆盖安装。

## 下载与安装

安装文件将在本 Release 的 Assets 中提供：

```text
chuxing-1.1.0.apk
```

系统要求：Android 8.0 或更高版本。

已经安装 `v1.0.1` 的用户可以直接覆盖安装，本地数据会继续保留。

## 更新内容

### 出行概况

- 首页改为出行概况，显示下一趟行程、发车时间和实时倒计时
- 新增出行次数统计，区分总计、今年和本月
- 新增常坐线路排行和走过的车站数
- 本地没有行程时，首页提供「导入历史行程」入口，可以一次导入邮箱里已经结束的行程并归档
- 有历史记录但没有未出发行程时，首页显示「暂无即将出发的行程」，不再留出空白
- 统计只覆盖本地已保存的行程，只计入状态为「有效」且已经过出发时间的行程，不统计里程和票款

### 导航与行程页

- 新增「首页」「行程」「设置」三项底栏，原先收在首页右上角菜单里的设置可以直接看到
- 「历史行程」改为行程页内的切换，不再单独占一个页面
- 支持左右滑动在「未出发」和「历史」之间切换，标签栏跟随滑动实时更新
- 未出发卡片的归档方式由向左滑动改为长按卡片弹出菜单，横向手势交给翻页
- 标签页之间使用淡入淡出，二级页面保留原来的水平推入动画

### 车站名展示

- 统一车站名的展示写法。12306 在 2020 年前后的邮件里对车站名的写法不一致（老邮件不写「站」，新邮件写），现在展示、通知、Google Wallet 卡片和统计都去掉末尾的「站」
- 常坐线路不再把同一线路拆成两条，「走过车站数」也不再重复计数
- 本地保存的行程仍保留邮件中的原始车站名，这项变化只影响展示和统计
