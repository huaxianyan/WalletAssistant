# 出行 v1.0.0

「出行」是一款在 Android 设备端导入、整理和提醒铁路行程的独立应用。首个正式版本支持 12306 购票、改签、候补兑现和退票邮件、截图 OCR、本地行程管理、精确提醒和可选的 Google Wallet 导出。

## 下载与安装

安装文件将在本 Release 的 Assets 中提供：

```text
chuxing-1.0.0.apk
```

系统要求：

```text
Android 8.0 或更高版本
```

应用不通过 Google Play 分发。安装时需要允许当前下载工具安装未知来源应用。后续版本必须使用相同 Release 证书且 `versionCode` 更高，才能覆盖安装并保留本地数据。

## 主要功能

### 导入行程

- 用户可自行配置使用 TLS IMAP 和专用密码或授权码的邮箱
- 首次点击邮箱同步且尚未配置时，说明凭据风险并进入邮箱配置
- 首次同步读取来自 `12306@rails.com.cn` 的铁路订单通知，后续只读取新增邮件
- 可选按 1～24 小时间隔自动检查邮箱，发现行程后通知用户确认
- 可从邮箱服务器返回的文件夹列表中指定同步文件夹，但需自行配置邮箱收信规则，确保铁路通知进入所选文件夹
- 手动同步显示连接、检查、读取邮件和整理行程的实时阶段
- 识别购票、改签、候补兑现和退票邮件
- 粘贴铁路订单通知正文
- 通过 Android 系统照片选择器导入截图
- 使用设备端 ML Kit 中文 OCR 读取截图文字
- 在保存前检查解析结果，缺失信息不猜测

### 管理行程

- 在设备端保存、查看和删除行程
- 将同订单中的不同车次拆分为独立行程，并合并同一行程的多位乘车人
- 保留已改签和已退票状态，部分退票不影响同订单中的其他车票
- 从首页向左滑动归档，并可在历史行程中恢复
- 可选在未来行程出发后自动归档
- 首次同步或重建索引时，可选择仅同步未出发行程，或导入历史行程并直接归档
- 后续增量同步始终应用购票、改签和退票状态更新

### 乘车提醒

- 提醒默认关闭，可设置新行程默认值和单个行程开关
- 发车前提醒支持 30 分钟～12 小时
- Android 16 支持发车前 15～60 分钟显示实时状态，并以 5 分钟为调整粒度
- 通知提供「已上车」和「取消提醒」操作
- 「已上车」结束提醒并归档，「取消提醒」只结束提醒

### Google Wallet

- 用户可以主动把已确认的最少行程信息添加至 Google Wallet
- Generic Pass 显示路线、车次、时间、座位、席别和乘车人
- 不包含、复制或模拟 12306 动态检票二维码
- Google Wallet 是可选导出目标，不影响应用内行程管理和提醒
- Publishing Access 已批准，正式卡片真机添加后不显示测试标记

## 权限说明

- **网络访问：**连接用户配置的 IMAP 邮箱和 Google Wallet
- **通知：**显示用户已开启的乘车提醒，以及自动同步发现的待确认行程
- **闹钟和提醒：**按用户设置的时间安排精确提醒，不会在系统时钟中创建闹钟
- **开机完成：**设备重启后恢复未来行程提醒
- **照片选择器：**只读取用户本次明确选择的截图，不申请整个照片库权限

## 隐私

邮箱地址和专用密码或授权码加密保存在 Android 设备上。原始邮件、候选邮件、导入截图和 OCR 文字不会发送到 NeKo7inA 运营的服务器。自动同步发现的待确认内容只保存结构化行程和同步游标，用户确认的行程保存在应用私有的本地数据库中，且不纳入 Android 应用数据云备份。

只有用户明确选择添加至 Google Wallet 时，已确认的最少行程字段才会直接提交给 Google Wallet。

完整说明：

https://chuxing.neko7ina.com/privacy/

## 已知边界

- 当前解析支持 12306 购票、改签、候补兑现和退票邮件，其他 12306 页面截图可能无法形成完整行程。
- OCR 结果受截图清晰度、裁剪范围和页面格式影响，保存前需要用户核对。
- 精确提醒需要用户授予 Android 「闹钟和提醒」特殊权限。
- Google Wallet 卡片不是车票、乘车凭证或动态检票二维码。
- 不保证第三方 Wallet 卡片显示在系统 At a Glance 区域。
