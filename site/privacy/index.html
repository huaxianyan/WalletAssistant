隐私政策

生效日期：2026 年 8 月 26 日

本隐私政策说明 Android 应用「出行」（以下简称「本应用」）如何访问、使用、存储和传输信息。本应用由 NeKo7inA 独立开发，不运营用于接收或存储用户 Gmail、截图、OCR 文字或行程数据的业务服务器。

1. 适用范围

本政策适用于本应用以及位于 chuxing.neko7ina.com 的公开静态网站。本应用与中国国家铁路集团有限公司、12306 或其关联机构不存在隶属、合作或官方授权关系。

2. 本应用处理的信息

2.1 Gmail 授权和邮件

只有在用户主动选择「从 Gmail 导入」并完成 Google 授权后，本应用才使用 https://www.googleapis.com/auth/gmail.readonly 权限：

  • 搜索与 12306 购票成功通知相匹配的候选邮件；
  • 读取候选邮件的发件人、主题和正文；
  • 在设备端解析车次、路线、出发时间、座位、乘车人和订单标识等行程信息。

本应用不会发送、修改或删除 Gmail 邮件。OAuth Access Token 仅用于当前授权和 Gmail API 请求，不写入本应用数据库。原始邮件和候选邮件不会上传到开发者运营的服务器。

2.2 粘贴文字和截图

用户可以主动粘贴购票通知正文，或通过 Android 系统照片选择器选择截图。本应用不申请访问整个照片库。截图通过应用内置的 ML Kit 中文文字识别模型在设备端处理，截图内容和 OCR 文字不会上传到开发者运营的服务器。

Google 提供的 SDK 可能依照其政策处理运行诊断、设备或 API 使用信息；本应用不会向其提供用于广告的邮件正文、截图或行程数据。

2.3 用户确认的行程

解析结果只有在用户检查并确认后才保存到应用私有的本地数据库。保存内容可能包括：

  • 出发站、目的站、车次和出发时间；
  • 车厢、座位和席别；
  • 乘车人姓名和订单标识；
  • 提醒、归档和自动归档设置。

这些信息用于展示行程、去重、提醒、归档和删除，不用于广告、信用评估或用户画像。设备操作系统可能按照用户的 Android 备份设置处理应用数据；NeKo7inA 无法访问用户的系统备份。

2.4 Google Wallet

Google Wallet 是完全可选的导出目标。只有用户在行程详情中明确点击添加按钮后，本应用才会把已确认的最少行程字段直接提交给 Google Wallet，包括车次、出发站、目的站、出发日期和时间、座位、席别及乘车人姓名。

Google Wallet 卡片不包含、复制或模拟 12306 动态检票二维码。提交到 Google Wallet 后，相关数据由 Google 按其隐私政策处理；用户可在 Google Wallet 中管理或删除卡片。

2.5 权限和设备状态

本应用可能请求或使用以下 Android 权限和能力：

  • 网络访问：连接 Google Identity、Gmail API 和 Google Wallet；
  • 通知：在用户开启单个行程提醒后显示乘车提醒；
  • 闹钟和提醒：在用户指定的时间安排精确提醒；
  • 开机完成：设备重启后恢复用户已开启的未来行程提醒；
  • 系统照片选择器：只读取用户本次明确选择的截图。

提醒默认关闭。拒绝通知或精确提醒权限不会影响本地导入和行程管理。

3. 数据传输和共享

本应用不会出售、出租或向广告平台、数据经纪商及信息转售方提供用户数据，也不会把 Gmail 数据用于广告或训练机器学习模型。

仅在以下情况下发生必要的数据传输：

  • 用户授权后，本应用直接从设备连接 Google Identity 和 Gmail API；
  • 用户明确选择添加卡片后，本应用直接从设备向 Google Wallet 提交已确认的最少行程字段；
  • 为遵守适用法律、保护用户安全或响应合法要求而必须处理信息时。

本应用对从 Google APIs 获得的信息的使用和传输遵守 Google API Services User Data Policy，包括 Limited Use requirements。

出行's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 保存期限和删除

  • OAuth Access Token、原始邮件、候选邮件、导入截图和 OCR 文字不保存到本应用的行程数据库；
  • 用户确认的行程保留在设备上，直到用户删除行程、清除应用数据或卸载应用；
  • 归档只改变本地行程状态，不代表删除；
  • Google Wallet 卡片需要由用户在 Google Wallet 中单独管理；
  • 用户可在 Google 账号的第三方连接设置中撤销本应用的 Gmail 授权。

由于 NeKo7inA 不持有用户的应用内行程数据库，因此无法从远程服务器查询或删除这些本地数据。

5. 静态网站

本网站由 Cloudflare 托管，不设置应用账号、不使用分析脚本、不投放广告、不设置由本站控制的跟踪 Cookie，也不提供收集个人信息的表单。Cloudflare 可能出于安全、运行和网络交付目的处理 IP 地址、User-Agent 和访问日志，具体以 Cloudflare 隐私政策为准。

6. 数据安全

本应用通过 Android 应用沙箱、本地私有数据库、HTTPS 和 Google 官方授权流程降低未授权访问风险。任何系统都无法保证绝对安全，用户应妥善保护设备锁屏凭据和 Google 账号。

7. 儿童隐私

本应用不是专门面向儿童设计的服务，也不会基于 Gmail 内容建立儿童用户档案。如果监护人认为儿童在不适当的情况下使用本应用，可以通过下方邮箱联系开发者。

8. 政策更新

当功能、权限或第三方服务发生实质变化时，本政策会同步更新，并在页面顶部标注新的生效日期。重大变化可能同时在 GitHub Release Notes 中说明。
